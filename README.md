# 🐍 Змейка с порталами

Классическая змейка в браузере с парой порталов: ныряешь в синий — выныриваешь из оранжевого (и наоборот).

Вся игра — один файл `index.html` без зависимостей и сборки.

## Как запустить

Откройте `index.html` в любом современном браузере (двойной клик по файлу).

## Управление

| Действие   | Клавиши                        |
|------------|--------------------------------|
| Движение   | `←` `↑` `↓` `→` или `W` `A` `S` `D` |
| Пауза      | `Пробел`                       |
| Заново     | `R`                            |
| На телефоне | свайпы по полю                |

## Правила

- 🍎 Яблоко — **+1** очко, змейка растёт и понемногу ускоряется.
- ⭐ Звезда — **+3** очка. Появляется иногда, убегает от головы змейки и через время исчезает (перед исчезновением мигает).
- 🌀 Порталы переезжают на новое место после каждых 5 съеденных яблок.
- Игра заканчивается, если врезаться в стену или в себя.

Рекорд сохраняется в браузере (`localStorage`).
